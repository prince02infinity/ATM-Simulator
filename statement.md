### 1. Introduction

For this project, I have created a simple ATM Simulator using Python. The idea behind this project is to understand how an ATM works and how we can use basic programming concepts to perform different banking operations.

The program runs in the terminal and allows a user to log in using a PIN. After logging in, the user can check their balance, deposit money, withdraw money, view a mini statement, and change their PIN.

### 2. Objectives

The main purpose of making this project is to apply what I have learned in Python Essentials. Through this project, I wanted to:

* Understand how functions work and how they make code easier to manage.
* Learn to use `if-else` statements and loops in a practical program.
* Practice taking input from users and checking whether it is valid.
* Understand how lists and dictionaries can be used to store transaction details.
* Learn how to divide a program into different Python files using modules.
* Build a small application that performs tasks similar to a real ATM.

### 3. What the Program Can Do

The ATM Simulator includes the following operations:

1. **Login:** The user enters a four-digit PIN to access the ATM. Three incorrect attempts will block access.
2. **Check Balance:** The user can see the current amount available in the account.
3. **Deposit Money:** The user can add money to the account by entering a valid amount.
4. **Withdraw Money:** The user can withdraw money if the amount is valid and enough balance is available.
5. **Mini Statement:** The program displays the successful deposits and withdrawals made during the current session.
6. **Change PIN:** The user can change the existing PIN after entering it correctly.
7. **Exit:** The user can leave the program by selecting the exit option.

The program also displays messages when the user enters an invalid amount or selects an incorrect menu option.

### 4. Requirements

**Functional Requirements**

* The program should check the user's PIN before allowing access.
* It should display the account balance.
* It should update the balance after a successful deposit or withdrawal.
* It should keep a record of successful transactions during the session.
* It should allow the user to change the PIN.
* It should provide an option to exit the program.

**Non-Functional Requirements**

* The menu should be simple and easy to understand.
* The program should handle incorrect inputs without stopping unexpectedly.
* The code should be organized into separate files so it is easier to read and maintain.
* The program should respond quickly to user choices.
* The instructions and messages should be clear to the user.

### 5. Scope and Limitations

This project is made for learning Python, so it is a basic simulation and not a real banking application. It supports only one account, and the balance, PIN, and transaction history are stored temporarily while the program is running.

When the program is closed, these details return to their initial values. The project does not use a database or connect to any actual bank.
